# UEShooterExampleEx

## Teleport

The player can teleport 10 meters forward upon pressing the T key. 

## Wall Run

Implemented a wall run feature similar to the Lucio ability in Overwatch. 
The player is able to run on walls.

## Wall Jump

Implemented a wall jump feature where the player can perform a lateral jump while running on a wall. 
This jump will push the player to the opposite direction of the wall, and higher than before.

## Multiplayer
The mechanicis were implemented for a multiplayer environment and integrated with the character replication system. 
To ensure multiplayer functionality was tested, a lag simulation of 500ms was used.
